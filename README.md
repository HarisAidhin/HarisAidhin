## About Me

I'm **Haris Aidhin Ramadhan**, an Information Systems student and cybersecurity enthusiast from Indonesia, passionate about web application security and penetration testing.

I actively participate in Bug Bounty programs and Coordinated Vulnerability Disclosure (CVD), focusing on identifying security weaknesses and helping organizations improve their digital security.

My approach is built around continuous learning, responsible research, and ethical security practices.

- Focused on **Web Application Security**
- Interested in **Penetration Testing & Vulnerability Research**
- Participating in **Bug Bounty & Responsible Disclosure**

- Committed to responsible and ethical security testing

## Featured Research

My research activities focus on identifying and documenting security vulnerabilities in web applications.

Some vulnerability categories I have explored include:

- Cross-Site Scripting (XSS)
- SQL Injection (SQLi)
- Open Redirect
- Host Header Injection
- Sensitive Information Disclosure
- Broken Access Control
- Insecure Session Management
- Improper Input Validation
- Subdomain Takeover
- Authentication & Authorization Issues

All security research is conducted with an emphasis on authorized testing, minimal impact, and responsible disclosure.
